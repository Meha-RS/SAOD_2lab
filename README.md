# Лабораторная работа 2. Сжатое префиксное дерево (Radix Tree)

## Описание
Реализация структуры данных «Radix tree» (сжатое префиксное дерево) на языке C. 
Ключ — строка (`char*`), значение — целое число (`uint32_t`).

## Структура проекта
* `inc/` — заголовочные файлы (`rtree.h`, `experiment.h`).
* `src/` — исходный код (`rtree.c`, `experiment.c`, `main.c`).
* `Makefile` — сборка проекта.
* `plot.plt` — скрипт gnuplot для построения графика.
* `plot_data.txt` — данные для графика (Создаётся автоматически и заполняется вручную по результатам замеров).

## Реализованные функции
* `rtree_create()` — создание дерева.
* `rtree_insert()` — вставка (включая расщепление / split).
* `rtree_lookup()` — поиск значения по ключу.
* `rtree_delete()` — удаление (включая склейку / merge).
* `rtree_print()` — вывод структуры дерева в консоль.
* `rtree_free()` — очистка памяти.

## Сборка и запуск

```bash
make run / rebuild / clean
```
